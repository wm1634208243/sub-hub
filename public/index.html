❓ 「纯规则分流」和「全托管聚合订阅」我该选哪一个？

• 纯规则分流（推荐）：适合你已有稳定机场，不想把机场节点导入第三方服务。只需在 Clash Verge Rev 中添加 JS 扩展脚本，即可零侵入为原订阅注入全套策略组、国内直连与防污染 DNS。
• 全托管聚合订阅：适合你购买了多家机场，希望由 SubHub 把多份节点清洗去重、测速合并为一个统一的 Clash / 小火箭 / Sing-Box 订阅链接。

❓ 聚合订阅 URL 与纯规则分流 URL 是使用同一个 Token 吗？

是的，统一使用此安全 Token。 每个 SubHub 用户拥有专属唯一的安全访问密钥（Token）。无论是全格式聚合订阅链接（/api/sub）、Clash 订阅（/api/clash.yaml）、Sing-Box 订阅（/api/sing-box.json）还是纯规则分流覆写脚本（/api/rules.js），均使用此专属 Token 统一鉴权。当你点击「重置 Token」或修改到期时间时，所有关联的订阅和规则直链都会同步更新受控。

❓ 拉取订阅提示 403 Forbidden？

请检查 URL 后面的 ?token=xxx 参数是否与页面顶部一致；若设置了订阅到期日且已过有效期，服务端也会返回 403。

❓ 手机端小火箭为什么没有进程分流？

移动操作系统（iOS / Android）受系统沙盒限制不支持获取应用进程名（PROCESS-NAME）。SubHub 服务端具备 UA 自动感知，已为移动端自动精简剔除进程规则，保证规则完全兼容。

❓ 如何实现规则或节点修改后即时同步？

在 SubHub Web 端点击右上角「保存发布」后，服务端内存即刻热重载，客户端右键点击「刷新订阅」或「更新」即可秒级拉取到最新规则与节点。

❓ 国内网站为什么会出现验证码或加载缓慢？

请前往「🎨 规则分流」开启 GEOSITE, cn 与 GEOIP, CN，并确保 DNS 设置了国内高优先级 Nameservers（如 223.5.5.5）。
